```
Halo Product Hunt! 👋

Saya Awiparo, developer dari Jurnal Guru.

Jurnal Guru adalah dashboard manajemen sekolah yang saya buat untuk membantu guru di Indonesia mengelola administrasi mengajar dengan lebih efisien.

Masalah yang saya lihat:
- Guru menghabiskan banyak waktu untuk administrasi manual
- Absensi, nilai, dan jurnal seringkali tersebar di berbagai tempat
- Tidak ada solusi gratis yang mudah digunakan

Solusi Jurnal Guru:
✅ Absensi digital - catat kehadiran dalam 10 detik per kelas
✅ Rekap otomatis - persentase kehadiran terhitung otomatis
✅ Nilai & KKM - kelola nilai dan pantau ketuntasan
✅ Jurnal mengajar - dokumentasikan materi dan kendala
✅ Gratis - tidak ada biaya untuk sekolah

Tech stack: Next.js, TypeScript, Cloudflare, D1 Database

Saya sangat terbuka untuk feedback dan saran. Terima kasih! 🙏
```
