# Strategi Harga & Penawaran — Jurnal Guru

## Ringkasan Produk

**Nama:** Jurnal Guru
**Kategori:** Education Technology
**Target:** Guru Indonesia (SD, SMP, SMA)
**Masalah:** Guru habis waktu untuk administrasi manual
**Solusi:** Dashboard digital untuk absensi, nilai, jurnal, jadwal

---

## Strategi Harga

### Model: Freemium

| Tier | Harga | Fitur |
|------|-------|-------|
| **Gratis** | Rp 0 | Absensi, nilai, jurnal, jadwal, data siswa (1 kelas) |
| **Pro** | Rp 49.000/bulan | Unlimited kelas, laporan lanjutan, export PDF, priorititas support |
| **Sekolah** | Rp 299.000/bulan | Multi-guru, dashboard admin, backup otomatis |

### Kenapa Harga Ini?

1. **Gratis (Rp 0)**
   - Menarik guru untuk coba
   - Membangun base pengguna
   - Bisa upgrade ke Pro jika butuh fitur lanjutan

2. **Pro (Rp 49.000/bulan)**
   - Setara 1 makan siang per hari
   - Hemat waktu 2 jam per hari = investasi yang worth it
   - Unlimited kelas untuk guru yang mengajar banyak kelas

3. **Sekolah (Rp 299.000/bulan)**
   - Untuk sekolah yang ingin pakai untuk semua guru
   - Dashboard admin untuk kepala sekolah
   - Backup otomatis data

## Struktur Penawaran

### 1. Core Deliverable (Apa yang didapat)
- Dashboard guru lengkap
- Absensi digital dengan rekap otomatis
- Pengelolaan nilai dan KKM
- Jurnal mengajar
- Jadwal mengajar
- Data siswa
- Template surat

### 2. Bonus Stack (Bonus tambahan)
- **Bonus 1:** Template RPP Kurikulum Merdeka (Rp 99.000 value)
- **Bonus 2:** Panduan Lengkap Absensi Digital (Rp 49.000 value)
- **Bonus 3:** Template Surat Resmi Sekolah (Rp 29.000 value)
- **Total Bonus:** Rp 177.000

### 3. Guarantee (Jaminan)
- **Garansi 30 Hari:** Jika tidak puas dalam 30 hari, uang kembali 100%
- Tidak ada pertanyaan

### 4. Scarcity/Urgency (Kelangkaan)
- **Harga Perkenalan:** Rp 29.000/bulan (dari Rp 49.000) untuk 100 guru pertama
- **Bonus Eksklusif:** Template RPP hanya untuk yang daftar bulan ini

### 5. Nama Penawaran
- **"Paket Guru Produktif"** — Dashboard + Bonus + Garansi

### 6. Harga + Struktur Pembayaran
- **Bulanan:** Rp 29.000/bulan (perkenalan)
- **Tahunan:** Rp 249.000/tahun (hemat 30%)
- **Sekali Bayar:** Rp 999.000 (selamanya)

## Value Equation

| Lever | Skor | Catatan |
|-------|------|---------|
| Dream Outcome | 9/10 | Guru ingin hemat waktu, fokus mengajar |
| Perceived Likelihood | 7/10 | Perlu lebih banyak testimoni |
| Time Delay | 9/10 | Langsung bisa dipakai |
| Effort & Sacrifice | 8/10 | Interface sederhana |

**Total:** 33/40 — Offer cukup kuat

---

## Pricing Psychology

1. **Anchoring:** Tampilkan harga Pro (Rp 49.000) sebelum harga Perkenalan (Rp 29.000)
2. **Decoy:** Tahunan (Rp 249.000) lebih menguntungkan dari bulanan
3. **Charm Pricing:** Rp 29.000 (bukan Rp 30.000)
4. **Social Proof:** "281 guru sudah menggunakan"
