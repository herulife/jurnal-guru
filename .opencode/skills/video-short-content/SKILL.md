# Video Short-Form Content — Jurnal Guru

Buat konten video pendek (Reels/TikTok/Shorts) untuk guru Indonesia. Bahasa Indonesia, hangat, solutif. **No school names.** Sinkron dengan skill `social-media-marketing`, `marketing-plan-seo`, `saas-marketing`.

## Format ideal (untuk Jurnal Guru)
- Durasi: **20–45 detik** (hook 2–3 dtk → isi → CTA). 2–3 detik pertama wajib hook.
- 9:16 vertikal (Reels/TikTok/Shorts).
- CTA pakai label: "Daftar gratis di link di bio" / "Open link ⬆️".

## Kerangka naskah (60/30/10 = hook/isi/CTA)
1. **HOOK (0–3 dtk):** pertanyaan/masalah guru.
   > "Masih rekap absen manual sampai lembur? 😩"
2. **ISI (3–30 dtk):** masalah → solusi dengan dashboard Jurnal Guru. Tunjukkan layar asli (screen-recording) + caption teks besar.
3. **CTA (pakatai detik):** satu aksi spesifik + link.
   > "Rapat ke gratis — kamu bisa bikin rekap otomatis dalam 2 menit. Cek bio untuk link!"

## Ide topik (template siap pakai)
- Tips praktis: "Cara bikin rekap nilai otomatis", "Template jurnal mengajar", "Absensi 5 menit".
- Before/after: "Kelola data dari kertas 🤔 → dashboard rapuh di satu tempat ✅".
- Feature walkthrough: Rapor, Kelompok, Google Sheets sync.
- Relatable guru: "Jumat sore, semua guru… tapi kamu sudah pulang karena jurnal selesai."

## Storyboard prompt (untuk membuat/editing)
- Buat 3–5 adegan: teks (opening) → Tampil dashboard (mid) → hasil/CTA (outro).
- TTS/voice-over opsional; sarankan audio memperjelas (tutorial jurnal).
- Tombol/subtitle untuk aksesibilitas & penonton tanpa suara.

## Editing & visual
- Gunakan editor favorit tim (CapCut, dll): BGM ringan, teks besar, subtitle otomatis, template brand stabil.
- Konsisten visual: primary `#0D7C66`, amber `#E8A317`, bg `#F5F3EF`, font Outfit/DM Sans.
- Utamakan screenshot asli dashboard agar kredibel (hindari gambaran generik/objektif berlebihan).

## Kalender posting (mingguan contoh)
| Hari | Format | Ide |
|------|--------|-----|
| Sen | Reel 30s | "Cara bikin rekap otomatis" |
| Rab | Story | cuplikan fitur + CTA link |
| Jum | Reel 20s | "Hemat jam kerja admin" |
| Sab | Reel | testimoni guru (anonim) |

## Workflow
1. Tentukan tujuan (awareness/registrasi) + platform/audience.
2. Tulis hook → naskah → adegan → editing → kalender.
3. Cantumkan bahasa Indonesia; link yang benar (landing `/` atau checkout promo).
4. Gunakan `generate-image` bila perlu ilustrasi; tampilkan prototype layar/dashboard saat walkthrough.
